## KodaChat

Uma aplicação web simples que permite usuários criarem contas, fazerem posts e interagirem entre si

## Sobre o projeto

Este projeto consiste em uma mini rede social onde os usuários podem:

- Criar uma conta
- Fazer login
- Criar publicações
- Visualizar posts de outros usuários
- Curtir ou comentar publicações

O objetivo do projeto é aplicar conceitos de desenvolvimento web, banco de dados e autenticação de usuários e segurança com JWT.

## Tecnologias Utilizadas

- Java Spring
- React
- Postgres
